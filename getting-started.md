# Getting Started

### Prerequisites

+ OpenWeather Account
+ API Key
+ Basic knowledge of Http methods
+ curl or postman (optional)

  ## Get an API Key

 * Create Openweather Account
 * go to API Key section
 * Generate an API Key
 * use key in API request

   note: Never use your real API Key in github repository

   compulsory : API key is required for API request.
